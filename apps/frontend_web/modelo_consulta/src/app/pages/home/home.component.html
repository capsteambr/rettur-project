Transparência & Segurança

Aviso Importante: Sobre o nome "OpenCNPJ"

O nome OpenCNPJ é utilizado por diferentes projetos e serviços independentes na internet. O projeto oficial mantido e sustentado pela iniciativa OpenCaramelo opera exclusivamente sob os domínios e canais oficiais listados abaixo:

Site Oficial https://opencnpj.com
Endpoint Oficial da API https://kitana.opencnpj.com
Repositório Oficial (GitHub) github.com/opencaramelo/opencnpj
Organização Mantenedora https://opencaramelo.com
Rate Limit

Limite de 300 req / min

A API possui atualmente um limite de 300 requisições por minuto por endereço IP. Esse limite existe para permitir o uso público e gratuito por toda a comunidade, evitando sobrecarga da infraestrutura e garantindo latência estável.

Livre Acesso

Sem API Key ou Cadastro

Acesso imediato sem burocracia. Não exigimos tokens de autenticação, cadastros prévios ou dados de pagamento. Basta enviar uma requisição HTTP GET padrão.

Padronização

Resposta em JSON Estruturado

Payload estruturado e limpo em UTF-8 contendo razão social, nome fantasia, CNAEs, situação cadastral e quadro de sócios e administradores (QSA).
