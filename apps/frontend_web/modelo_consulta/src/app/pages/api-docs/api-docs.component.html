Códigos de Resposta HTTP

Padrões de retorno da API

Código HTTP Status Significado e Tratamento Recomendado
200 OK Sucesso CNPJ localizado e dados cadastrais retornados com sucesso no payload.
400 Bad Request Requisição Inválida O CNPJ informado possui quantidade incorreta de dígitos ou caracteres incompatíveis.
404 Not Found Não Encontrado O CNPJ não está cadastrado ou não foi localizado nas bases oficiais da Receita Federal.
429 Too Many Requests Rate Limit Excedido O limite de 300 requisições por minuto por IP foi ultrapassado. Aguarde alguns instantes antes de reenviar.
500 / 503 Internal Error Erro Interno / Instabilidade Instabilidade temporária nos serviços de dados governamentais. Tente novamente em instantes.

Rate Limit & Boas Práticas

Orientações para consumo escalável, responsável e de alta performance

Armazenamento em Cache Local

Recomendamos salvar em banco de dados local ou cache (Redis/Memcached) os dados de empresas já consultadas. A ficha de um CNPJ raramente sofre alterações diárias.

300 Requisições por Minuto

O limite de 300 req/min equivale a uma média de 5 requisições por segundo por IP, sendo mais que suficiente para checkout de e-commerces, onboarding e rotinas de ERP.

Uso Sustentável e Responsável

O serviço é gratuito para toda a comunidade. Evite loops não controlados ou varreduras agressivas em lote para mantermos o projeto 100% aberto e sem cobranças.
